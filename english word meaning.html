✅ইংরেজিতে বাক্য তৈরির ২০টি নিয়ম।  Basic Sentence Patterns
 
1. Subject + Verb
যখন Subject নিজেই কাজটি করে, Object লাগে না।
Structure:
Subject + Verb
Examples:
• She runs.
• He sleeps.

2. Subject + Verb + Object
Subject কোনো কাজ করে এবং সেই কাজটি কার ওপর হচ্ছে, সেটাই Object।
Structure:
Subject + Verb + Object
Examples:
• I read books.
• She likes coffee.

3. Subject + Verb + Complement
Verb-এর পরে Subject সম্পর্কে অতিরিক্ত তথ্য দেয় (name, quality, identity)।
Structure:
Subject + be verb + Complement
Examples:
• He is happy.
• They are students.

4.  Subject + Auxiliary Verb + Main Verb
Continuous tense বা চলমান কাজ বোঝাতে Auxiliary verb ব্যবহার হয়।
Structure:
Subject + am/is/are + Verb-ing
Examples:
• I am learning English.
• She is cooking.

5. Subject + Modal Verb + Base Verb
Ability, advice, permission, possibility বোঝাতে Modal verb ব্যবহার হয়।
Structure:
Subject + can / should / must + Verb
Examples:
• I can speak English.
• He should study.

6.  There + is/are + Noun
কোনো কিছু কোথাও আছে—এটা বলার জন্য।
Structure:
There + is/are + Noun
Examples:
• There is a pen on the table.
• There are many students.

7. Subject + Verb + Adverb
কাজটি কীভাবে হচ্ছে, তা বোঝাতে Adverb বসে।
Structure:
Subject + Verb + Adverb
Examples:
• He runs fast.
• She speaks clearly.

8. Subject + Linking Verb + Adjective
Sense verb (look, smell, feel) দিয়ে Subject-এর অবস্থা বোঝানো হয়।
Structure:
Subject + Verb + Adjective
Examples:
• The flower smells nice.
• He looks tired.

9. Subject + Verb + Place
কাজটি কোথায় হচ্ছে, তা বোঝাতে Place যোগ হয়।
Structure:
Subject + Verb + Place
Examples:
• She lives in Dhaka.
• I work at an office.

10.  Subject + Verb + Time
রুল:
কাজটি কখন হচ্ছে, তা বোঝাতে Time word বসে।
Structure:
Subject + Verb + Time
Examples:
• I wake up early.
• He arrived yesterday.

11.  Subject + Verb + Object + Place
রুল:
কাজ → কার ওপর → কোথায় (এই ক্রমে বাক্য সাজে)।
Structure:
Subject + Verb + Object + Place
Example:
• I kept the book on the table.

12.  Subject + Verb + Object + Time
রুল:
কাজ → Object → কখন—এই অর্ডার মেনে চলতে হয়।
Structure:
Subject + Verb + Object + Time
Example:
• She finished the work yesterday.

13.   Imperative Sentence (Command)
রুল:
আদেশ, অনুরোধ বা নির্দেশ দিলে Subject থাকে না।
Structure:
Verb + Object
Examples:
• Close the door.
• Sit down.

14. Let + Object + Base Verb
রুল:
কাউকে কিছু করতে দেওয়া বা প্রস্তাব দেওয়ার জন্য।
Structure:
Let + Object + Verb
Examples:
• Let me explain.
• Let him go.

15.  Subject + Verb + Infinitive
রুল:
Verb-এর পরে to + verb বসে উদ্দেশ্য বোঝাতে।
Structure:
Subject + Verb + to + Verb
Example:
• I want to learn English.

16.  Subject + Verb + Gerund
রুল:
কিছু verb-এর পরে verb+ing বসে।
Structure:
Subject + Verb + Verb-ing
Example:
• She enjoys reading.

17.   Subject + Verb + Object + Infinitive
রুল:
কাউকে কিছু করতে বলা / বলা / অনুরোধ করা বোঝায়।
Structure:
Subject + Verb + Object + to + Verb
Example:
• I asked him to help me.

18. Subject + Verb + Gerund
রুল:
কিছু verb-এর পরে সরাসরি gerund আসে।
Structure:
Subject + Verb + Verb-ing
Example:
• She stopped talking.

19. Yes/No Question Pattern
রুল:
প্রশ্ন বানাতে Auxiliary verb আগে বসে।
Structure:
Auxiliary + Subject + Verb?
Examples:
• Do you like tea?
• Did he call you?

20.   Wh-Question Pattern
রুল:
Wh-word দিয়ে প্রশ্ন শুরু হয়।
Structure:
Wh-word + Auxiliary + Subject + Verb?
Example:
• Where do you live?
